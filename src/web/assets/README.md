# Embedded SPA assets

Generated by `scripts/embed_web_assets.py` (also via PlatformIO pre-script and `make frontend`):

| File | Role |
|------|------|
| `web_ui.bin` | Concatenated gzip payloads |
| `web_ui_blob.S` | Assembler stub (`.incbin`) for flash rodata |
| `web_ui_manifest.h` | Path → offset/length/MIME/cache table |

Do not edit these files by hand. Rebuild with:

```bash
make frontend
```
