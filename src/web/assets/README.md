# Embedded SPA assets

Generated by `scripts/embed_web_assets.py` (also via the PlatformIO pre-script):

| File | Role |
|------|------|
| `web_ui.bin` | Concatenated asset payloads (currently raw for captive-browser compatibility) |
| `web_ui_blob.S` | Assembler stub (`.incbin`) for flash rodata |
| `web_ui_manifest.h` | Path → offset/length/MIME/cache table |

Do not edit these files by hand. Rebuild with:

```bash
(cd frontend && npm ci && npm run build)
python3 scripts/embed_web_assets.py
```
