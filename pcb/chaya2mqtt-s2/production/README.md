# Fertigungsdaten Rev A2

Enthalten sind Gerber für alle vier Kupferlagen, Pasten-, Masken-,
Bestückungsdruck- und Konturlagen, Excellon-Bohrdaten samt Bohrplan, Positions-
und Bestückungslisten sowie PDF-/SVG-Prüfplots.

Die Exporte entsprechen dem vollständig gerouteten 46 × 45-mm-Layout. KiCad
10 meldet für Schaltplan und PCB jeweils 0 Verstöße sowie 0 offene
Verbindungen. Damit ist der Datensatz für eine Prototypbestellung konsistent,
aber noch nicht serienfreigegeben.

Vor einer Serienfreigabe sind elektrischer Bring-up,
E-Paper-Hochspannungsmessung, USB-Signalintegrität, FPC-/Gehäuseprobe,
LDO-Thermik und ein 2,4-GHz-RF-Test erforderlich.
