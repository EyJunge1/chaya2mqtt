# Manufacturing data Rev A2

This directory contains Gerber files for all four copper layers, paste, mask,
silkscreen, and outline layers, Excellon drill data including a drill map,
position and bill-of-materials lists, and PDF/SVG inspection plots.

The exports correspond to the fully routed 46 × 45 mm layout. KiCad 10 reports
0 violations for both the schematic and PCB, as well as 0 unconnected items.
The data set is therefore consistent for a prototype order but has not yet
been approved for production.

Electrical bring-up, e-paper high-voltage measurements, USB signal integrity
testing, an FPC/enclosure fit check, LDO thermal testing, and a 2.4 GHz RF test
are required before production approval.
